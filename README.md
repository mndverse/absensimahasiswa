# Sistem Daftar Hadir Mahasiswa

**Proyek Pemrograman Web — Kelompok 3**

## Deskripsi
Sistem Daftar Hadir Mahasiswa merupakan aplikasi berbasis web
yang dirancang untuk membantu pencatatan dan pengelolaan
kehadiran mahasiswa secara digital.

## Fitur
- Menampilkan halaman beranda.
- Mengelola data mahasiswa.
- Mencatat kehadiran mahasiswa.
- Menampilkan status kehadiran, seperti Hadir, Izin, Sakit, dan Alpa.
- Menyimpan data kehadiran menggunakan localStorage.
- Menyediakan halaman tentang aplikasi.

## Teknologi
- Ember.js
- JavaScript
- HTML
- CSS
- Vite

## Pengembang
Kelompok 3
